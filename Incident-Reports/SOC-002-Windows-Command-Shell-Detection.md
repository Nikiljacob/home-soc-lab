\# SOC-002 - Windows Command Shell Custom Detection



\## Summary



A custom Wazuh detection rule was created to identify Windows Command Prompt

(cmd.exe) process creation events generated by Sysmon.



The rule successfully detected a controlled launch of cmd.exe on the Windows

lab endpoint.



\## Environment



\- Endpoint: lab-windows-01

\- Operating System: Windows 11 Enterprise Evaluation

\- Wazuh Agent ID: 002

\- Endpoint IP: 192.168.56.104

\- Telemetry Source: Microsoft Sysmon

\- Event Channel: Microsoft-Windows-Sysmon/Operational



\## Detection



\- Custom Rule ID: 100100

\- Rule Level: 6

\- Description: Custom detection: Windows Command Prompt launched

\- Sysmon Event ID: 1

\- Event Type: Process Create



\## Process Evidence



\- Process: C:\\Windows\\System32\\cmd.exe

\- Command Line: "C:\\WINDOWS\\system32\\cmd.exe"

\- User: DESKTOP-K47D631\\nikil

\- Integrity Level: Medium

\- Parent Process:

&#x20; C:\\Windows\\System32\\WindowsPowerShell\\v1.0\\powershell.exe



\## Process Relationship



PowerShell

&#x20;   |

&#x20;   +-- cmd.exe



The parent-child relationship is consistent with the controlled test because

cmd.exe was intentionally launched from PowerShell.



\## Analyst Assessment



The alert was classified as benign expected activity.



The command shell was intentionally launched during a controlled lab test to

validate Sysmon telemetry collection and the custom Wazuh rule.



The presence of cmd.exe alone is not sufficient evidence of malicious

activity. In a production environment, additional context would be required,

including command-line arguments, parent process, user, privilege level,

network activity, and correlated events.



\## Outcome



The custom detection worked successfully.



This validated the complete detection pipeline:



Windows process creation

\-> Sysmon Event ID 1

\-> Windows Event Log

\-> Wazuh Agent

\-> Wazuh Manager

\-> Custom Rule 100100

\-> Level 6 Alert

\-> Analyst Investigation



\## Lessons Learned



\- Sysmon provides detailed Windows process telemetry.

\- Event ID 1 represents process creation.

\- Parent-child process relationships help reconstruct execution activity.

\- Custom Wazuh rules can convert selected telemetry into actionable alerts.

\- An alert does not automatically indicate malicious activity.

\- Detection rules should be tuned to reduce false positives.
